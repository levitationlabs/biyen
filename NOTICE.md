## Summary of Modifications (AGPL §5a)

1. **Brand Identity & Aesthetics:**
   - Rebranded user-facing interfaces to **Biyen Photos** with the **biyen** wordmark and amber glow accent dot.
   - Introduced the **Si Gani** transparent vector elephant mascot across empty states, onboarding, and upload workflows.
   - Replaced default colors with Biyen's **Terracotta (`#C8502E`)** primary and **Warm Archival Cream (`#FBF8F2`)** background tokens across mobile and web.
   - Integrated the **Outfit** typeface for headings, wordmark, and brand elements.

2. **Network & Endpoint Configuration:**
   - Reconfigured API, upload, public album, and web domains to single-level flat subdomains under `biyen.levitation.web.id`.
   - Updated file and thumbnail delivery to route through the primary API endpoints.

3. **Localization & Default Experience:**
   - Configured Bahasa Indonesia (`id-ID`) as the primary default locale alongside English (`en-US`).
   - Cleaned upstream string files to ensure unified naming and clear terminology.

4. **UI Layouts & Navigation:**
   - Desktop web navigation rail on the left and mobile bottom navigation matching the mobile application.
   - Minimalist sidebar structure with single-line storage presentation and explicit plan states.
   - Public album footer with AGPLv3 attribution and abuse reporting.
